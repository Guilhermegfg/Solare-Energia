# ☀️ Solare Energia

Site demonstrativo para o segmento de **energia solar**, desenvolvido pela **GFGTech** para mostrar como uma empresa do setor pode transformar o site em uma ferramenta de geração de oportunidades.

A experiência foi construída com foco em **simulação de economia, apresentação das soluções e conversão para orçamento via WhatsApp**.

## 🚀 Principais recursos

- Layout moderno, responsivo e mobile-first
- Hero section com proposta de valor e CTAs
- Soluções para clientes residenciais, empresariais e rurais
- Simulador demonstrativo de economia
- Dimensionamento aproximado do sistema
- Resultado enviado diretamente para WhatsApp
- Projetos demonstrativos
- FAQ interativo
- Integração com Google Maps
- Atendimento local em Goianésia e região
- SEO local básico
- Animações leves sem bibliotecas externas

## 🧮 Simulador

O visitante informa o valor médio da conta e o tipo de imóvel. O JavaScript gera uma **estimativa inicial demonstrativa** de economia, potência e geração do sistema.

O resultado pode ser encaminhado para o WhatsApp, criando uma jornada simples entre interesse e atendimento comercial.

> Os cálculos são apenas demonstrativos e não substituem dimensionamento técnico.
