# Solare Energia

Site fictício de demonstração para o nicho de energia solar, criado em HTML, CSS e JavaScript puro.

## Recursos

- Layout moderno, responsivo e mobile-first
- Hero section com CTA
- Soluções residencial, empresarial e rural
- Simulador demonstrativo de economia
- Envio do resultado para WhatsApp
- Projetos fictícios
- FAQ interativo
- Integração com Google Maps para Goianésia - GO
- Links para WhatsApp e Instagram
- SEO local básico
- Animações leves sem dependências
